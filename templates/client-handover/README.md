# Client handover template

How we let a client's own Claude continue the work from a voice file alone: a repo with the studio, the client's brand assets, `inbox/` (the approved audio) and `outbox/` (results), plus these two files. Copy them, replace `{{CLIENT}}` and `{{SPEAKER}}`, adapt the rules to the agreement, and test with a sample voice. Keep the hard rules: only approved audio; never publish for the client; captions are the speaker's own words and a native reader proofreads them; complete last sentence.
